# Color Collector — v1.0

One second, one color.

## Comment ça marche ?

1. Une nouvelle couleur RGB est tirée chaque seconde lorsque le jeu est actif.
2. Le bouton Pause arrête les tirages jusqu\'à la reprise. Les couleurs acquises apparaissent sur la fresque avec un scintillement.
3. Utilisez la molette pour zoomer, faites glisser la fresque pour la déplacer, ou cliquez sur Dézoom ou 100 %..
4. Collectionnez les succès et les trophées, mais soyez patient !
5. Votre progression est enregistrée localement. Vous pouvez l\'exporter, importer une sauvegarde ou la réinitialiser.

## Sauvegardes

Le jeu permet d'exporter ou d'importer une sauvegarde au format `.ccol`. Les données ne sont jamais envoyées sur le serveur.

## Images

Le jeu permet l'upload et le traitement de fichier image. Tout se fait localement sans jamais transiter sur le serveur.

## Confidentialité

Le traitement des images et des couleurs s'effectue dans le navigateur. Le projet ne contient aucun service d'analyse d'audience ni publicité.
